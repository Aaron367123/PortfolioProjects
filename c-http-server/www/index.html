This page came off the disk through a bounded work queue and a fixed pool of worker threads: no frameworks, no libraries beyond the C standard library, pthreads and the OS socket API.

Request lifecycle

  1. accept() on the main thread
  2. bounded queue — full? reply 503 immediately
  3. worker pool pops the connection
  4. parser validates request line & headers
  5. handler streams the file in 64 KiB chunks
  6. keep-alive loop until idle timeout or Connection: close
