About Myousik

Started as a four-person college project. Rebuilt so that every button actually does something.

From mockup to working app

Version 1 — the class project

  • Static HTML pages with jQuery 1.4.2 form checks.
  • "Log in" and "Send feedback" just linked to a success page — nothing was saved.
  • Song cards and artists were hard-coded in the markup.
  • One mp3 behind a play button.

Version 2 — the full-stack rebuild

  • Express REST API with SQLite, migrations and seed data.
  • Real accounts: scrypt-hashed passwords and server-side sessions.
  • Song library with search, sorting, pagination and full CRUD.
  • Personal playlists you can reorder, plus feedback that is stored.
  • The same validation rules run in the browser and on the server.
  • Automated API tests with Node's built-in test runner.
